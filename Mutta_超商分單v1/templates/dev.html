說明

觸發開發者模式

在主頁的 📦 圖示上連點 5 下，即可跳轉至此頁面。此入口對一般使用者不可見。

商品售價對照

設定「售價 → 分類名稱」的對應關係。當新商品上架時，在此新增對應的售價與分類名稱，下次分單即可自動識別。

贈品邏輯

贈品的精細判斷（根據規格欄文字、數量、折扣）定義在伺服器端的 app/core_logic.py 的 gift() 函式中，需直接修改程式碼。

預設密碼

初始密碼為 admin1234，請立即至「修改密碼」分頁更換。

安全說明

  • 密碼以 SHA-256 雜湊儲存，不存明文
  • 開發者 API 需在 Header 帶 X-Dev-Token，一般使用者無法呼叫
  • 此頁面網址（/dev）可以在 Nginx 設定中限制 IP，進一步強化安全
